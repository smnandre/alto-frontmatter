# Support

Use the [documentation](docs/index.md), then the
[issue tracker](https://github.com/altophp/frontmatter/issues) for questions or bugs.

Include PHP and package versions, a minimal document including its fences, the
method called, and the expected and actual values or exception. Preserve exact
whitespace when reporting byte offsets, line numbers, or indentation errors.
Remove private metadata and body content before sharing the sample.

Mention whether the default or a custom decoder/renderer is used. File-read
failures should include the relevant I/O error separately from parsing errors.
For a feature request, explain the metadata workflow and desired result.
